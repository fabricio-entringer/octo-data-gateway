  <files>app/api/admin/stats_service.py, app/api/admin/stats_schema.py, app/api/admin/controller.py</files>
  <action>
Create `app/api/admin/stats_schema.py` with Pydantic models:
- `EndpointStats`: endpoint name, request_count, success_count, fail_count, avg_response_time_ms
- `UserStats`: user_id, user_name, request_count, last_active
- `TimeSeriesPoint`: timestamp (hour/day bucket), count
- `DashboardStats`:
  - total_users: int
  - active_api_keys: int (not expired)
  - expired_api_keys: int
  - total_requests_24h: int
  - total_requests_7d: int
  - total_requests_30d: int
  - success_rate_24h: float (percentage)
  - avg_response_time_ms: float
  - requests_per_endpoint: list[EndpointStats]
  - top_users: list[UserStats] (top 10 by request count)
  - requests_over_time: list[TimeSeriesPoint] (last 7 days, daily buckets)
  - status_code_distribution: dict[str, int] (e.g., {"200": 150, "401": 5})

Create `app/api/admin/stats_service.py`:
- `StatsService` class
- `get_dashboard_stats(self) -> DashboardStats` — aggregates data from user_usage TinyDB table:
  - Read all usage records, filter by time windows (24h, 7d, 30d)
  - Compute per-endpoint breakdown: group by endpoint field
  - Compute top users: group by user_id, count, sort descending, take top 10
  - Get user names by joining with user_database
  - Compute time series: group by day for last 7 days
  - Compute status code distribution from status_code field
  - Get user counts from user_database (total, active keys, expired)
- `get_endpoint_stats(self, endpoint: str, days: int = 7) -> EndpointStats`
- `get_user_activity(self, user_id: str, days: int = 30) -> list[TimeSeriesPoint]`

Add API endpoints to `app/api/admin/controller.py`:
- `GET /admin/stats/dashboard` — returns DashboardStats JSON (MASTER/ADMIN scope)
- `GET /admin/stats/endpoint/{endpoint}` — returns EndpointStats
- `GET /admin/stats/user/{user_id}/activity` — returns user activity time series

Import user_usage table directly: `from app.database.user_usage import user_usage` (the TinyDB table object).
Use `from datetime import datetime, timedelta` for time filtering.

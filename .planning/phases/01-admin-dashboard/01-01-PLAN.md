  <files>app/cache/__init__.py, app/cache/manager.py, app/cache/config.py</files>
  <action>
Create `app/cache/config.py` with default TTL values:
```python
DEFAULT_TTL = {
    "bitcoin_price": 30,       # 30 seconds
    "bitcoin_prices": 30,      # 30 seconds
    "email_validate": 3600,    # 1 hour
    "iban_validate": 86400,    # 24 hours
}
```

Create `app/cache/manager.py` with a thread-safe singleton `CacheManager`:
- `_cache: dict[str, CacheEntry]` where CacheEntry has value, timestamp, ttl_seconds
- `_ttl_config: dict[str, int]` initialized from DEFAULT_TTL
- `get(key: str) -> Any | None` — returns value if not expired, else None and removes entry
- `set(key: str, value: Any, endpoint: str)` — stores with TTL from _ttl_config[endpoint]
- `set_ttl(endpoint: str, ttl_seconds: int)` — updates TTL config at runtime (immediate effect per D-03)
- `get_ttl_config() -> dict[str, int]` — returns current TTL config
- `flush(endpoint: str | None = None)` — flush specific endpoint keys or all
- `get_cache_stats() -> dict` — returns entry count, per-endpoint counts, memory estimate
- Use `threading.Lock` for thread safety
- Module-level singleton: `cache_manager = CacheManager()`

Create `app/cache/__init__.py` exporting `cache_manager` and `CacheManager`.

Do NOT use Redis or any external dependency. Pure Python dict-based.
  </action>

  <files>app/admin/templates/partials/user_form.html, app/admin/routes.py, app/admin/static/js/admin.js</files>
  <action>
Add routes to `app/admin/routes.py`:
- `GET /admin/partials/user-form` — returns empty user_form.html partial (for new user modal)
- `GET /admin/partials/user-form/{user_id}` — returns pre-filled user_form.html (for edit modal)
- `POST /admin/users` — creates user via UserService().add_user(), returns updated user_table partial
- `PUT /admin/users/{user_id}` — updates user via UserService().update_user(), returns updated user_table partial
- `POST /admin/users/{user_id}/renew-key` — calls UserService().renew_api_key() with form data (days_valid or expires_at), returns updated user_row partial

Create `app/admin/templates/partials/user_form.html`:
- Tailwind-styled modal overlay (dark backdrop, centered white card)
- Form fields:
  - Name (text input, required)
  - Email (email input)
  - Description (textarea)
  - Scopes (checkboxes for each scope in Scopes enum, MASTER checkbox only shown if current user is MASTER)
  - API Key Expiration (datetime-local input, optional)
- If editing (user data passed): pre-fill all fields, change submit text to "Update User"
- Submit button uses `hx-post="/admin/users"` (create) or `hx-put="/admin/users/{id}"` (edit)
- `hx-target="#user-table-body" hx-swap="innerHTML"` to refresh table after success
- Close button / click-outside to dismiss modal
- Show validation errors inline (HTMX swap error responses)

Add "Renew API Key" modal:
- Triggered by renew button on user_row
- Options: "Extend by X days" (number input) OR "Set expiry date" (datetime-local)
- Submit via `hx-post="/admin/users/{id}/renew-key"`

- `copyToClipboard(apiKey)` function — copies to clipboard, shows brief "Copied!" tooltip
